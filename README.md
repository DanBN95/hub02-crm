# hub02-crm

Internal CRM for the Hub02 team — Monday-style task management with backlog, sprints, priority, and team assignments.

## Stack
- **Monorepo**: pnpm workspaces
- **Frontend**: React 19 + Vite + Tailwind v4 + TanStack Query
- **Backend**: NestJS 11 + Prisma + Postgres
- **Auth**: Google SSO (Passport) + JWT
- **Deploy**: Vercel (web) + Railway (api)
